# Spend Wise Buddy


A responsive web application designed to help college students and young professionals in India track their income, expenses, budgets, and savings.

## Features

- **Dashboard:** View total income, expenses, available balance, and monthly budget.
- **Transaction Management:** Track income and expenses.
- **Budget Management:** Set monthly budgets and monitor spending.
- **Expense Categories:** Organize and analyze spending by category.
- **Reports & Charts:** Visualize financial activity and spending patterns.
- **Responsive Design:** Use the application on laptops and mobile devices.
- **Indian Currency Support:** Displays amounts in Indian Rupees (₹).

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
