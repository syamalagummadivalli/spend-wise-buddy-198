# Spend Wise Buddy

Build a modern, responsive personal finance tracker web app called SpendSmart, designed for college students and young professionals in India.

DESIGN:

Clean, professional dashboard with a light background, navy text, and subtle green accents.

Use Indian Rupees (₹) throughout.

Make the layout responsive for laptops and mobile phones.

Use attractive summary cards, simple charts, and clear navigation.

DASHBOARD:

Total Income: ₹65,000

Total Expenses: ₹54,250

Available Balance: ₹10,750

Monthly Budget: ₹60,000

Budget progress should correctly show approximately 90.4%.

EXPENSE CATEGORIES:

Bills: ₹28,500

Food: ₹11,750

Education: ₹6,000

Travel: ₹4,500

Shopping: ₹3,500

The category amounts must add up to the total expenses. The available balance must equal total income minus total expenses. Charts must use the same data shown in the dashboard.

FEATURES:

Dashboard with income, expenses, balance, budget progress, and spending charts.

Add income and expense transactions with amount, category, date, and description.

Transaction history with edit and delete options.

Monthly budget setting and category-wise spending summaries.

Clear empty states and helpful validation messages.

Make the main interactions functional using a suitable simple data-storage approach. Include realistic sample transactions that match the summary totals. Do not add payment processing, banking connections, or unnecessary features.

First create the dashboard and navigation. Keep the design beginner-friendly, consistent, and polished.
